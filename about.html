About PackEV

A small Pokemon TCG toolkit for collectors and pack watchers.

Set list is refreshed from the public Pokemon TCG API. Card prices come from TCGPlayer / Cardmarket when available; history grows from free daily catalog snapshots.

Set pages include card images, rarity-based pull estimates, and TCGPlayer/Cardmarket prices when available.

Sealed EV

Pack EV is a two-bucket estimate already stored on each set: average “dead” pack value, plus a chase card that hits once every N packs. Box EV is that pack EV times the packs in a booster box (36, unless the set has no standard box). ETB EV is pack EV times the packs in an Elite Trainer Box for that era, plus any promo dollars you add. The EV board ranks sets on those figures. Costs are what you type, or an optional MSRP hint that is labeled as MSRP. Sold prices are not invented, and price charts only plot stored snapshots.

Data and estimates are updated as sources change.
